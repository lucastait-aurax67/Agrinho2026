# Agro Forte, Futuro Sustentável 🌾

> Projeto desenvolvido para o **Concurso Agrinho 2026** focado na disseminação de práticas agrícolas conscientes e sustentáveis.

## 📌 Objetivo do Projeto
O objetivo desta página web é conscientizar a comunidade escolar e produtores sobre a viabilidade e a importância do equilíbrio entre a alta produtividade no campo e a preservação do meio ambiente. Através de uma interface limpa, interativa e acessível, o usuário compreende os pilares da sustentabilidade no agronegócio.

## 💡 Justificativa
O agronegócio é o motor econômico do país, porém seu futuro depende diretamente da conservação dos recursos naturais. Promover o tema "Agro forte, futuro sustentável" prepara a nova geração (estudantes do Ensino Médio) para aplicar e valorizar práticas que mitiguem os impactos climáticos garantindo a segurança alimentar de amanhã.

---

## 🚀 Tecnologias Utilizadas
* **HTML5 Semântico:** Estruturação utilizando tags recomendadas e elementos interativos.
* **CSS3 Moderno:** Customização visual harmônica, efeitos de transição/hover e layout responsivo com Flexbox e Media Queries.
* **JavaScript (Vanilla):** Manipulação dinâmica de elementos da árvore DOM, variáveis de processamento e acessibilidade (Modo Escuro).

---

## 🛠️ Funcionalidades e Critérios de Avaliação Atendidos
* **Manipulação do DOM:** O JavaScript exibe uma mensagem personalizada de boas-vindas e controla a visibilidade de elementos baseado na ação do usuário.
* **Usabilidade Avançada:** Implementação de um botão de alternância de tema (Modo Escuro) para melhor leitura.
* **Responsividade Total:** Folha de estilos adaptada para dispositivos móveis (smartphones e tablets).
* **Código Limpo:** Arquivos completamente identados e documentados com comentários funcionais explicativos.

---

## 📁 Organização de Pastas
As mídias e códigos estão separados para manter a integridade do console do navegador livre de erros:
* `/` (Raiz): Contém os códigos estruturais (`index.html`, `style.css`, `script.js`).
* `/imagens`: Destinada a armazenar mídias customizadas geradas em ferramentas como o *Canva*.
